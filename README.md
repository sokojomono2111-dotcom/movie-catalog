# 🎬 Консольний каталог фільмів (Movie Catalog)

Навчальний проєкт з розробки консольної системи управління каталогом фільмів на мові C++. Проєкт створено в рамках виконання практичних робіт з програмування та проєктування ПЗ.

---

## 📌 Основні можливості
- **Додавання фільмів:** Введення назви, жанру, року випуску та рейтингу (від 1 до 10).
- **Перегляд каталогу:** Відображення повного списку збережених фільмів у зручному форматі.
- **Пошук за назвою:** Швидкий пошук фільму за його назвою.
- **Збереження даних:** Автоматичне збереження та завантаження каталогу з локального файлу `movies.txt`.
- **Українізований інтерфейс:** Повна підтримка кирилиці в консолі Windows (`UTF-8 / chcp 65001`).
