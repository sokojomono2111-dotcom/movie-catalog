# Movie Catalog App

Простий консольний додаток мовою C++ для зручного управління каталогом фільмів.

## Команда
* **CineCode**

## Основні функції
* Додавання фільму (назва, жанр, рік випуску, рейтинг)
* Перегляд повного списку збережених фільмів
* Пошук фільму за назвою
* Збереження та завантаження даних із файлу `movies.txt`

## Інструкція із запуску
1. Скомпілювати файл `main.cpp` у будь-якому середовищі (VS Code, Code::Blocks) або в OnlineGDB.
2. Запустити створений програмою файл.
